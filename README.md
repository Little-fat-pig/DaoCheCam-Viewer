# 倒车摄像子（DaoCheCam-Viewer）

> ⚠️ **本项目仅供个人学习交流使用，禁止任何商业用途。使用产生的一切后果自负，详见文末《免责声明》。**


主手机上的倒车画面查看端。父子双 App 中的「子」：全屏横屏观看「倒车摄像父」推来的画面，并支持把屏幕上看到的画面连同麦克风声音录成 MP4 存入相册。

## 功能

- WebView 壳装载内置页面，系统级横屏锁定（sensorLandscape），沉浸全屏、屏幕常亮，无状态栏无多余文字
- 自动发现：同网段扫描探测父端（/shot.jpg），找到即自动连接播放
- fetch + ReadableStream 自写 MJPEG 解析器（SOI/EOI 标记），createImageBitmap + canvas 绘制并丢帧，保证流畅不卡
- 断流看门狗：6 秒无新帧自动重连
- 右下 ● 录像按钮：MediaProjection 录屏（含麦克风），MP4 存相册 Movies/倒车影像，首次使用弹系统授权

## 使用

1. 主手机安装，打开即锁定横屏
2. 确保与「倒车摄像父」在同一 WiFi/热点，页面自动发现并播放
3. 点 ● 开始录像 → 允许系统录屏授权 → 再点 ● 停止，视频在相册

## 构建

- Java + WebView + MediaProjection，无第三方依赖
- AGP 7.3.1 / Gradle 7.4 / JDK 17 / compileSdk 34，minSdk 24
- `gradle assembleRelease` 生成 APK，自行签名后安装

## 配套

- 推流端：DaoCheCam-Server「倒车摄像父」
